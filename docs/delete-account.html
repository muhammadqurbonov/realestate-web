Удаление аккаунта Green Home

Green Home — приложение для сотрудников и менеджеров по работе с недвижимостью.

Как запросить удаление аккаунта

Для удаления аккаунта Green Home и связанных с ним данных пользователь может:

  1. Связаться с администрацией компании через WhatsApp.
  2. Указать, что он хочет удалить аккаунт Green Home.
  3. Указать номер телефона, связанный с аккаунтом.

Отправить запрос на удаление аккаунта через WhatsApp

Какие данные удаляются

После подтверждения запроса удаляются аккаунт пользователя, номер телефона, данные авторизации и связанные с аккаунтом персональные данные, если их хранение не требуется по закону или для обеспечения безопасности.

Срок удаления

Запрос рассматривается администрацией. Удаление аккаунта и соответствующих персональных данных производится в течение 30 дней после подтверждения запроса.

Данные, которые могут сохраняться

Некоторые данные могут сохраняться, если это необходимо для соблюдения требований законодательства, разрешения споров или обеспечения безопасности. Такие данные хранятся только в течение необходимого срока.
